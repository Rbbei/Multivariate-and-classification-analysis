# Statistical Analysis: PCA and Diabetes Classification

## Overview

This repository contains two statistical analyses developed as part of an academic project within the Master's Degree in Statistics and Operations Research.

The project explores two different areas of statistical analysis using R:

1. **Principal Component Analysis (PCA):** dimensionality reduction and exploratory analysis of decathlon performance data.
2. **Diabetes Classification:** application and comparison of statistical classification methods using the Pima Indians Diabetes dataset.

## Project 1 – Principal Component Analysis (PCA)

The first exercise applies Principal Component Analysis to decathlon data using the `decathlon2` dataset.

### Objectives
- Reduce the dimensionality of the dataset.
- Analyse the relationships between athletic performance variables.
- Identify the contribution of variables to the principal components.
- Visualise athletes and variables in the principal component space.
- Interpret the main patterns and correlations in the data.

### Methods and Tools
- Principal Component Analysis (PCA).
- Data standardisation.
- Eigenvalues and explained variance.
- Variable loadings and correlations.
- Principal component visualisation.

**R packages:** `FactoMineR`, `factoextra`.

## Project 2 – Diabetes Classification

The second exercise explores statistical classification methods using the Pima Indians Diabetes dataset, comparing different approaches to predict diabetes status.

### Objectives
- Build statistical classification models.
- Compare the predictive performance of different methods.
- Analyse classification errors using confusion matrices.
- Evaluate the strengths and limitations of each model.

### Methods
- Linear Discriminant Analysis (LDA).
- Quadratic Discriminant Analysis (QDA).
- Logistic Regression.

**R packages:** `MASS`, `klaR`.
